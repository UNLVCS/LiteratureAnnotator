## What is Semantic Entropy?

In this context semantic entropy is a measure of how confident a given Language Model is in its generated responses.
A lower score indicates higher confidence in model's generated data. A higher score indicates the model is guessing wildly, i.e. hallucination.



$$H = -\sum_{i=1}^{k}  p_i' \log\bigl(p_i'\bigr)$$


## Steps
### Model Sampling
* Given a prompt and an accompanying context the model is tasked with generating a response 10 different times. The temperature is usually set high (~1.0) in order to allow as much creative freedom for the answers generated by the model.

### Semantic Clustering
* Using a **Greedy Clustering** method, clusters from the 10 samples are formed by passing the generated clusters through a *cross-encoder*. 

    * For example you start off with no existing clusters, only the 10 samples. You take one sample $S_1$ and pass it through a cross-encoder model to create the first cluster $c_1$.
    * Next you take your second sample $S_2$ and compare against the leader of cluster $c_1$. Often times the leader is simply the first sample that formed the cluster.
    * Repeat until you have run through all the samples. At the worst case you'd have 10 different clusters.

### Turn Cluster Counts into Probabilities
    
* For a given cluster $c_i$ with $k$ samples, the probability of that cluster is $P(c_i) = \dfrac{|c_i|}{10}$
* Repeat for all clusters.

### Semantic Entropy
* Using the standard **Shannon Entropy** formula we calculate the certainty or confusion of the model.

$$H = -\sum_{i=1}^{k}  P(c_i) \log\bigl(P(c_i)\bigr)$$

* Decide on a threshold to decide if the model is hallucinating or not. This is something that can and should be tuned later on. For example, Low Entropy can be entropy values <0.5 and will be flagged as acceptable and high entropy can be >0.5 and will be flagged as hallucinating.
